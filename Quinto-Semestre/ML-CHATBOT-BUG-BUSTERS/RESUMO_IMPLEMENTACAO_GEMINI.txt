🆘 PROBLEMAS?

═══════════════════════════════════════════════════════════════════════════════

❌ "GEMINI_API_KEY not found"
   → Verifique se .env existe em: ML-CHATBOT-BUG-BUSTERS/.env
   → Verifique se tem a chave dentro

❌ "401 Unauthorized"
   → Chave inválida. Gere nova em https://aistudio.google.com/app/apikey

❌ "API não conecta"
   → Abra terminal e execute: 
     cd PROJETO_SISTEMA_DIAGNOSTICO/03_API
     python -m uvicorn api_biomedicina:app --port 8000

❌ "module google.generativeai not found"
   → Execute: pip install google-generativeai python-dotenv
